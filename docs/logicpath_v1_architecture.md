# LogicPath v1: Counterfactual Transformation Graph Transformer

LogicPath v1 models AX-b as a sequence of transformations from the premise to
the hypothesis. It is independent of PIIG and does not require Wikidata or
Wiktionary. The graph is built dynamically from each sentence pair.

## Core idea

Instead of asking only which evidence is present, the model asks which
operations could transform the premise into the hypothesis:

```text
premise state
    -> lexical relation
    -> quantifier or polarity change
    -> logical transformation
    -> hypothesis state
```

## Graph

Nodes include:

- `premise_state` and `hypothesis_state`, containing the original sentences;
- `premise_unit` and `hypothesis_unit`, containing selected lexical or logical
  units;
- `transformation`, describing an operation such as
  `hypernym_generalization` or `negation_flip`.

Edges are typed as `contains`, `lexical_relation`, `supports`, `contradicts`,
or `operation`. The graph builder currently detects lexical identity,
synonymy, hypernymy, hyponymy, antonymy, polarity changes, quantifier changes,
conjunction changes, conditional structure, numeric changes, and temporal
cues.

## Transformer and graph interaction

The pair Transformer produces the main semantic representation. The graph
nodes use the same input embedding space and are updated by relation-aware
Graph Transformer layers. The final classifier receives:

```text
pair representation
graph representation
absolute difference(pair, graph)
elementwise product(pair, graph)
predicted transformation features
predicted inverse-transformation features
```

There is no fusion gate. The classifier learns how to compose the features.

## Counterfactual or inverse supervision

The graph exposes a second target describing the inverse transformation. For
example, the inverse of `hypernym_generalization` is
`hyponym_specialization`. This auxiliary objective encourages the graph
representation to preserve directionality instead of treating the pair as an
unordered bag of words.

This first version uses deterministic transformation annotations generated by
the pair. Future versions can replace them with learned counterfactual graph
edits and explicit contrastive examples.

## Running

```bash
poetry run graphnli-train \
  --models logicpath_v1 \
  --model-name bert-base-multilingual-cased \
  --training-protocol mnli \
  --train-manifest data/manifests/mnli_train_2000_stratified.jsonl \
  --seeds 42 \
  --epochs 8 \
  --batch-size 32 \
  --eval-languages en \
  --selection-metric nli3/macro_f1 \
  --device mps \
  --output-dir runs
```

The graph size is controlled by `--max-logicpath-nodes` and
`--max-logicpath-len`.

When `--save-piig-explanations` is enabled, the evaluation step saves one JSON
and layered, left-to-right SVG graph per AX-b subtype under
`explanations/axb/`. It also saves up to five transformation-rich examples in
`explanations/axb/transformation_examples/`. The SVG node colors and edge
widths reflect the normalized Graph Transformer attention.
